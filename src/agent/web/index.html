The commit gate

Every tool call waits for quiet.

You speak. The model may plan a tool. The gate holds that call until you have been quiet. If you continue, the call is dropped before it is logged. If you finish, it runs once.

  1. 01

    Heard

    Your words stream in while you are still talking. A turn that sounds unfinished is held for the rest.

  2. 02

    Holding

    A call the model plans waits at the gate until you have been quiet for the whole window, 0.6 s by default.

  3. 03

    Decided

    Keep talking and the call is dropped before it reaches the tool log. Stay quiet and it runs once; a repeat is reused, not re-run.

    ExecutedDropped
  4. 04

    Said

    The reply is grounded in the tool result. A call that never ran comes back as superseded, so the agent cannot claim it.
