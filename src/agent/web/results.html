How the gate works

You speak. The model may plan a tool. The gate holds that call until you have been quiet. If you continue, the call is dropped before it is logged. If you finish, it runs once.

An identical call in the same room runs once; a repeat reuses the first result. A dropped call returns as superseded, so the reply cannot claim it happened.

Run it locally

Start both workers, then leave them running

The voice worker is named interra-benchmark. The camera worker keeps the name interra-camera-troubleshooter; do not set the voice name there.

# voice worker
INTERRA_FDB_AGENT_NAME=interra-benchmark .venv/bin/python -m agent.fdb_livekit dev
# camera worker, second terminal
.venv/bin/python -m agent.extension_livekit dev
# this page
.venv/bin/python -m agent.demo_page
# voice worker
$env:INTERRA_FDB_AGENT_NAME = "interra-benchmark"
.\.venv\Scripts\python.exe -m agent.fdb_livekit dev
# camera worker, second window
.\.venv\Scripts\python.exe -m agent.extension_livekit dev
# this page
.\.venv\Scripts\python.exe -m agent.demo_page
